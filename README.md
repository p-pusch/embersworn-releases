# Embersworn

A top-down action RPG with roguelite runs: short seeded runs through
procedurally generated rooms, run-only boons, and permanent character
progression (levels and a passive tree, loot and crafting, skill gems).
Three classes (Warrior, Archer, Witch), five dungeon tiers, the Nightmare
Dungeon, the Restless Domain and Nightmare+.

This repository only hosts the game's downloads.

## Download and play (Windows, 64-bit)

1. Open [**Releases**](../../releases/latest) and download
   `Embersworn-vX.Y.Z-windows.zip`.
2. Unzip it and run `Embersworn.exe`. It's a single file; there's nothing to
   install.

The exe isn't code-signed, so Windows SmartScreen may warn the first time:
click **More info → Run anyway**.

Saves and settings are stored in `%APPDATA%\Godot\app_userdata\Embersworn\`,
so they carry over when you update to a new version.

## Controls

| Action | Key |
| --- | --- |
| Move | WASD / arrow keys |
| Skills | Left mouse / Right mouse / Q |
| Dash | Space |
| Interact | E |
| Inventory | I |
| Passive tree | P |
| Show Nightmare+ mods | hold Tab |
| Menu | Esc |
| Fullscreen | F11 or Alt+Enter |
